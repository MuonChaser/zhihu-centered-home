# 知乎 · 简净居中

一个 Tampermonkey / Violentmonkey 用户脚本：把知乎网页版首页、普通问题页、回答详情页与专栏文章页的内容置于页面中央，隐藏右侧栏与无关推广框，并把顶栏精简为知乎 Logo 与居中的搜索框。问题页只保留问题标题与问题描述。搜索页和个人主页不受影响。

## 安装

1. 在 Firefox 中安装 Tampermonkey 或 Violentmonkey。
2. 点击 **[自动安装 / 更新“知乎 · 简净居中”](https://github.com/MuonChaser/zhihu-centered-home/raw/refs/heads/main/zhihu-centered-home.user.js)**。
3. 在脚本管理器的安装页确认安装，然后刷新知乎首页、普通问题页、回答详情页或专栏文章页。

已经安装旧版本时，再次打开安装链接即可更新到最新版。

## 最高强度防闪

仅安装用户脚本也会启用完整防闪门控。若希望进一步覆盖“用户脚本管理器尚未开始执行”的极早首帧，可同时安装 Stylus 防闪层：

1. 安装 Firefox 扩展 [Stylus](https://addons.mozilla.org/firefox/addon/styl-us/)。
2. 打开 **[安装 / 更新“知乎 · 简净居中（Stylus 防闪增强）”](https://raw.githubusercontent.com/MuonChaser/zhihu-centered-home/main/zhihu-centered-home.user.css)**。
3. 在 Stylus 安装页确认安装；主用户脚本继续保持启用。

两层采用完全相同且自动校验版本的 CSS，不会改变功能分工：

- Stylus 将最终布局样式保存在本地，在页面首次绘制阶段直接应用，不依赖刷新时访问 GitHub。
- 用户脚本启动后立即隐藏页面根节点，并使用与当前主题一致的纯色画布。
- 脚本会等待当前路由的真实主栏结构出现，且连续两帧稳定后才显示页面。
- React 挂载期间使用临时深层观察器；首屏动画和过渡暂时关闭。
- 若知乎加载失败，4 秒超时保护会恢复页面，不会永久空白。
- 最近一次浅色 / 深色主题缓存在当前标签页会话中，用于刷新首帧选择正确背景。

Tampermonkey 安装后的用户脚本本身已经保存在浏览器本地，正常刷新不会重新下载 GitHub 文件；因此额外缓存脚本文本不会改善首帧速度。GitHub 只用于安装和定期检查更新。

## 浅色 / 深色模式

- 在页面地址末尾添加 `?theme=dark`，使用知乎原生深色模式。
- 添加 `?theme=light`，切换回知乎原生浅色模式。
- 也可以双击顶栏空白区域，在浅色和深色之间即时切换；当前地址的 `theme` 参数会同步更新。
- 地址已有其他参数时，使用 `&theme=dark` 或 `&theme=light`。
- 不添加 `theme` 参数时，不干预知乎当前的主题设置。

例如：首页可使用 `https://www.zhihu.com/?theme=dark`，问题页可使用 `https://www.zhihu.com/question/12628881447?theme=dark`。

## 效果

- 首页信息流、普通问题页、回答详情页和专栏文章主体保持知乎原生主栏宽度并水平居中。
- 顶栏使用始终一致的半透明磨砂背景与轻阴影，隐藏频道导航、直答、创作、消息、私信和头像，只保留知乎 Logo 与严格居中的 560px 搜索框。
- 支持通过 `theme=dark` / `theme=light` 切换知乎原生深浅主题，自定义磨砂顶栏会同步适配。
- 双击搜索框、按钮或知乎 Logo 不会触发主题切换。
- 点击顶栏的知乎 Logo 会刷新当前页面，不会把问题页或回答页强制跳回首页。
- 顶栏样式不随滚动位置切换，避免滚动或返回顶部时出现视觉跳变。
- 隐藏搜索框中由知乎动态填入的推荐占位文字，输入区域默认保持空白。
- 隐藏空搜索框下拉层中的“搜索发现”，保留个人搜索历史和输入后的正常搜索建议。
- 隐藏首页推广横幅与发布卡片、问题页右侧栏以及滚动时重复出现的问题标题栏。
- 问题头采用严格白名单，只显示问题标题和问题描述；话题标签、影视/书籍卡片、动态推荐以及“关注问题 / 写回答 / 邀请回答 / 评论 / 分享”等操作全部隐藏。
- 问题标题和描述保留知乎原生视觉样式，并与回答卡片严格对齐在同一条 694px 中轴线上。
- 专栏文章保留原生 654px 阅读正文与 20px 内边距，隐藏右侧栏并将整体 694px 容器居中。
- 页面在 `document-start` 阶段先隐藏，样式和路由标记连续两帧稳定后再显示；同时保留超时保护，避免闪现知乎原始布局或异常时长期空白。
- 窄屏（小于 1000px）不改变知乎原有的响应式布局。

## 维护

知乎可能调整网页的 CSS 类名。如果右侧栏重新出现，请在 issue 中附上浏览器版本、页面链接和截图（请打码个人信息）。

修改主脚本 CSS 后，运行 `node scripts/build-usercss.cjs` 重新生成 Stylus 文件，并用 `node scripts/build-usercss.cjs --check` 检查两者是否同步。
